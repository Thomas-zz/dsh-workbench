# 待安排任务栏、拖动与默认估时验证

## 交互

点击「待安排」在日历下方展开内嵌任务栏，不再打开模态弹窗。任务栏显示标题、项目、默认估时；拖完保持展开，可连续安排。清单支持拖到某一天、插入已有事项之前；时间轴按 15 分钟吸附具体落点；支持拖回任务栏。周视图的日期也支持放入事项。历史封存日不接受直接拖入。

拖动提供任务缩略影像、源事项淡化、目标日期高亮、插入线、时间落点提示、边缘滚动、保存反馈和落位动画。Esc 取消；顶部撤销可以还原安排。提供「安排至…」下拉作为键盘和触屏替代操作。遵循 reduced-motion，不播放位置移动与展开动画。

## 估时

打开计划会为缺少估时的个人行动发起独立 estimate 整理模式，使用现有共用模型。用户不用先填估时；返回前显示「约 30m」作为临时值。该模式只更新 estimateMinutes，不允许新增、拆分、改名、改状态、改归属或排期。保留已有估时，模型思考期间的手动估时优先；期间拖动日期可保留并正常补估时。

后台繁忙时等待当前整理；整理中加快界面刷新。调用失败保留原值，任务栏可重试估时。默认估时仍是模型建议，可以手动调整。未使用真实用户数据或付费模型进行本次验收；隔离预览使用模拟流返回估时来验证完整调用链。
