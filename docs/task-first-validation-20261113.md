# 任务为基本单位：项目聚合与上下文编辑

日期：2026-11-13。本轮替代首轮「原任务转成项目容器」和全局宽版弹窗的设计。

## 最终行为

- 日清单、本周汇总和项目页统一混合排列普通任务、日程与项目。只有项目有展开按钮，默认展开全部相关子项，包括已完成；普通任务无展开按钮。项目内部不重复展示所属项目名称。
- 排期仍以任务为单位。任务详情中的「创建关联项目」新建一个不同 ID 的项目，再关联原任务；保留任务 ID、类型、状态、日期、开始时间、估时、说明、证据及进展。重复操作不重复建项目。直接更新任务类型为项目会被拒绝，防止其他调用入口清空排期。
- 时间轴和清单使用 480px 紧凑编辑窗；项目、日期、时间、估时、截止、状态直接显示，说明材料与进展默认折叠。项目页保留 1040px 宽版详情。
- 已完成使用主题紫色边线及实色「已完成」徽标，移除深绿色完成时间块。
- 具体时间日程在对应时段显示橘黄色块；全天日程在时间轴内显示「全天 · 未指定时间」标记，不放在日期头部。全天标记在 08:00 的显示位置仅为视图投影，不写入实际时间、不消耗容量，不能直接拖动或缩放；可打开编辑窗设定具体时间。
