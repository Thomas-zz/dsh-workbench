## 首轮交互与数据（见上述修正）

- 任务详情改为宽版双栏面板：标题、说明、项目、日期、开始时间、估时、截止日期和状态直接可见；保存按钮固定在底部。窄屏优先显示关键字段，来源与材料在后。
- 任务可直接转为长期项目，保留原 ID、说明、来源及进展。项目可手动添加节点，不恢复自动拆分功能。已有项目标签可转换成正式项目并关联原事项。
- `kind=project` 是长期容器，不作为一条待办计数，不跨日、跨周顺延。旧 `goal` 数据保持兼容，在界面按项目展示。
- 周视图根据这一周实际安排及历史记录自动汇总项目与独立事项；项目默认展开，分别显示本周未完成和已完成。未排期和下周节点不混入本周。项目页可切换本周/全部节点。
- `kind=event` 是固定日期日程，有全天或具体时间两种方式；不会自动顺延，不参与行动估时。具体时间的日程占用排期空间，全天截止标记不消耗工作容量。
- 截止日期可一键建立关联日程；重复点击更新已有日程，不重复创建。
- 完成时间块使用深绿色实底、白色文字和“已完成”标记，清单完成项保持展开。

## IMAP 配置与运行

入口：助手设置 → 邮件接入 · IMAP。

填写 IMAP 主机、端口、TLS/STARTTLS、登录账号、自己的收件地址、授权码、文件夹（默认 INBOX）。可保存配置、测试连接、立即收取，或启用自动收取。

- 默认不启用自动收取；可设置频率。自动收取仅在 DSH Host 运行时执行。
- 初次默认读取最近 7 天，此后按服务器 UIDVALIDITY 和 UID 增量读取，每轮最多 20 封。
- 只读打开文件夹，不修改已读状态；读取正文部分，不下载附件。优先纯文本，HTML 转为文本。每封最多下载 200 KB 正文、最多带入 10,000 字符。
- 当前支持一个账号和一个文件夹，按“我的收件地址”判断直接收件/抄送；不读取收件人不匹配或无可读正文的邮件，并记录跳过数量和原因。
- 邮件正文通过工作台共用模型提取个人处理、确认事项和日程。模型没有邮件发送、命令执行工具；邮件内容被标记为不可信材料。导入需要本人责任判断及匹配邮件原文的证据。
- 行动无明确安排日期时进入待安排，旧日期行动也进入待安排；固定日程保留原日期。新邮件不会因同名旧任务已完成而被吞掉。
- 处理进度和导入结果一起保存，失败不推进游标，支持重试；重复邮件与已有事项去重。
- 授权码存放在工作台数据目录的 `mail-account.json`，文件权限 0600，不存入 `state.json`、状态 API 或模型提示词；保存后前端清空授权码输入。
