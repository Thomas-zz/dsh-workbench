## 当前交互

- 导航为「计划 / 项目 / 学习 / 整理记录」。公共随手记始终位于右上角，不再按日期重复出现，也不再提供「随手记与结果」页。
- 随手记支持长文本，晚间默认 22:00 或手动整理。从原始记录日期解释「明天」，重试也保留原日期；失败保留待整理内容，成功后关联实际生成的任务。
- 多步骤事项以周目标承载，阶段行动通过稳定 parentId 关联。周视图展示各阶段、日期和完成数量；日清单及时间块展示所属目标。现有行动可主动要求拆成阶段。
- 新增和编辑采用紧凑浮层：标题、日期、时间与估时；项目、父目标、硬截止及备注默认折叠。支持回车提交、中文输入法保护、空白时段框选新增，以及窄屏重新定位。
- 移除顶部大块统计和每天的记事区。1320×850 预览中日历滚动区域高 705px；未排时间收成入口，短时间块使用单行。无日期旧事项保留在「待安排」入口。
- 「帮我排一下」让共用模型确定行动顺序，再按可用时段分配当天时间，保留已有时间块。容量不足时缩短 scheduledMinutes，estimateMinutes 保留完整预估，必要时允许重叠；编辑浮层说明两者差异。
- 右上角「助手设置」统一任务与学习模型；学习设置链接同一个入口。迁移优先沿用原学习模型，其次任务模型，未指定时使用宿主默认。
- 整理记录显示执行时间、触发方式、状态、实际模型、来源数量与片段、生成或更新的目标和行动，最多保留 60 轮。执行中展示阶段，失败或进程中断可以重试。
- 任务整理使用独立 llm.stream，不向正常执行会话插入记账任务。定时执行遇到运行中的 Agent 延后，手动执行独立进行。普通轮询保持 15 秒，整理进行中加快刷新。
